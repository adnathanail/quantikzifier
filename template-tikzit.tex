% A standalone diagram has no bookmarks, but hyperref still writes an .out

%   every single run. Turning bookmarks off stops the .out being written.
% Set here rather than in the bundled circuits.tikzdefs so it also covers
%   user-supplied .tikzdefs files, which load hyperref just the same
\PassOptionsToPackage{bookmarks=false}{hyperref}
